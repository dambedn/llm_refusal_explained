7. BASELINE DIFFERENCE MAPS
The user then provided Plotly code for an animated UMAP of safe prompts and asked: "plot the differences".

The notebook was updated to compare each prompt's current condition label with its baseline label. The comparison matches prompts using their IDs and uses ground truth to define a descriptive ordinal desirability mapping.

For safe prompts:
over_refusal -> partial_refusal -> helpful_engagement

For unsafe prompts:
harmful_compliance -> partial_compliance -> correct_refusal

The code classifies changes as:
- Improved: movement toward the desired behavior.
- No change: the judge label is identical to baseline.
- Worsened: movement away from the desired behavior.
- Other transition: a label change not captured by the ordinal improvement/worsening scale.

These ordinal scores are used only as a descriptive visualization aid. They do not establish that the categories are equally spaced.

10. IMPORTANT METHODOLOGICAL CONSIDERATIONS

A. Fixed coordinates
For condition-to-condition difference maps, each prompt should retain the same UMAP coordinates across all animation frames. Otherwise, apparent movement may be caused by recalculating the embedding rather than a change in model behavior. The current difference-map approach keeps coordinates fixed and changes point colors.

B. Paired baseline comparisons
The difference maps rely on matching the same prompt across conditions. The notebook matches observations using prompt IDs. This should be validated to ensure each non-baseline prompt has exactly one corresponding baseline observation.

C. UMAP is exploratory
UMAP can reveal patterns in high-dimensional semantic representations, but nearby points are not necessarily behaviorally equivalent, cluster separation does not establish statistical significance, prompt wording and semantic similarity can influence clusters, and the visualizations should complement rather than replace statistical tests.

D. Judge labels
The difference maps reflect the judge's classifications. They are not independent measurements of model behavior. The results should be described as changes in judge-classified behavior unless the judge labels have been independently validated.

E. Ordinal mapping
The improved/worsened categories are useful for communicating direction, but the original judge categories are categorical. The report should retain the original labels and explain the ordinal mapping instead of treating score differences as continuous behavioral measurements.
